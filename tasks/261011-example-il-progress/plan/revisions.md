# 수정 요청과 처리 기록

자연어로 요청하면 에이전트가 아래 형식으로 기록한다. 필수 입력 양식은 없다.
예: “PDF 7쪽의 그림을 더 크게. 수치와 결론은 유지해줘.”
예: “S03을 두 장으로 나누고, 배경은 줄여줘. 총 10분은 유지해줘.”
현재 승인 상태는 [contracts.md](contracts.md), 처리 규칙은 저장소의 docs/revisions.md를 따른다.
이 기록은 승인 증거를 대체하지 않으며, 승인 필드를 직접 수정하지 않는다.
