# 설명용 삽화 제작 기록

2026-10-13 OpenAI built-in image_gen으로 제작. AI 삽화이며 실험 사진·측정 데이터가 아니다. 원본 그림 파일은 픽셀 수정 없이 복사했다. 아래 사양으로 재생성할 수 있으나 동일한 픽셀 결과를 보장하지 않는다.

공통: 넓은 흰 배경, 기술 교과서 스타일, 은색·파란 로봇과 두 손가락 그리퍼, 청록색 큐브·파란 트레이, 큰 물체 실루엣. 삽화 안의 문구·숫자·로고·수치·수식 금지. 설명 문구는 slides.md의 네이티브 텍스트·캡션 사용.

## bc-illustrated.png

세 장면: (1) 사람이 leader 로봇을 조작해 follower 그리퍼로 물체를 시연하고 카메라가 관측. (2) 관측 이미지와 행동 벡터를 짝지어 일반적인 정책 신경망의 학습 예로 제시. (3) 사람이 없는 자율 실행에서 로봇이 큐브를 트레이로 이동. 두 장면 연결 화살표. 보상·강화학습 기호 제외. ALOHA의 정확한 설계 재현을 주장하지 않음.

첫 생성본은 관측 이미지가 행동 벡터로 변환되는 순서로 오해할 수 있어 가운데 패널만 수정. 이미지와 행동을 공통 그룹 안에 별도로 놓고 각각 학습 그림으로 연결. 시연·실행 장면은 보존.

## distribution-shift-illustrated.png

BC 삽화의 로봇 디자인·그림체를 참조. 두 행 각각 세 장면: 위는 그리퍼 정렬 → 성공 파지 → 트레이 배치, 아래는 빗나간 접근 → 물체가 밀림·빈 파지 → 빈 그리퍼만 트레이로 이동. 마지막 아래 장면에서도 큐브는 테이블 위에 남겨 실패를 명확히 표현. 같은 카메라 관점, 큰 물체·그리퍼, 행 구분은 사람/정책 기호와 슬라이드 캡션. 특정 모델의 실제 실패·오차 크기를 주장하지 않음.

## dagger-illustrated.png

BC 삽화의 그림체를 참조. 세 장면: 정책이 잘못 방문한 관측 상태 → 전문가가 그 상태의 화면에서 바람직한 행동 방향을 라벨링 → 새 관측·행동 쌍을 기존 데이터 카드에 누적해 재학습. 얇은 되돌림 화살표로 반복 절차 표시. 사람은 태블릿에서 행동을 표시하며 로봇을 직접 건드리지 않음. 새 정책의 성공을 그리지 않음. 방향 화살표는 개념 표기이며 측정 제어 명령 아님.
