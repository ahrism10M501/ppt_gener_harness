# 기본 개념 | Fundamentals

## 월드 모델

### 월드 모델은 현재 관측과 행동에서 미래를 예측한다

- 관측으로 현재 상태를 추정한다
- 행동·목표를 조건으로 미래 변화를 예측한다
- 예측을 정책 학습·계획·평가에 활용한다

$$p(x_{t+1:t+H}\mid x_t,a_{t:t+H-1},l)$$

![예측과 의사결정의 순환](figures/world-model-loop.png "리뷰 식 (1): 관측·행동 → 미래 예측 → 의사결정. 언어 목표 l과 저수준 행동 a를 구분해 연구자가 제작")

::: source
Hou et al., 2026, §2.1, 식 (1). arXiv:2605.00080v1.
:::

::: notes
S01 · 100초. 기준 자료는 Hou et al., World Model for Robot Learning: A Comprehensive Survey, arXiv:2605.00080v1, 2026-04-30이다. 제공 PDF: sources/World Model for Robot Learning: A Comprehensive.pdf. 공개 자료 확인일은 2026-10-11이다.

정책이 지금 무엇을 할지 정한다면, 월드 모델은 그 행동 뒤에 무엇이 일어날지 예측한다. 상태 x는 이미지, 압축된 표현, 구조화된 상태 등이 될 수 있다. H는 예측 구간, a는 저수준 행동, l은 언어 지시나 목표다. 모든 모델이 이 조건을 전부 사용하는 것은 아니다. 직접 보이지 않는 상태는 관측과 과거 이력으로 추정한다. 리뷰는 로봇 의사결정에 유용한 미래 예측을 중심으로 정의한다.
:::

## 월드 모델

### 그럴듯한 미래 영상만으로 제어에 유용함을 입증할 수 없다

- 영상 품질: 장면이 자연스럽게 이어지는가
- 행동 일관성: 입력한 행동의 결과가 맞는가
- 제어 효용: 예측을 써서 과제를 수행하는가
- 언어 목표와 저수준 행동 조건을 구분한다

::: source
Hou et al., 2026, §2.1·§7.1. arXiv:2605.00080v1.
:::

::: notes
S02 · 80초. 설명용 가정이다. 로봇이 컵을 왼쪽으로 밀라는 명령을 받았는데 영상에서는 컵이 자연스럽게 오른쪽으로 움직인다고 해 보자. 영상이 보기 좋아도 해당 행동의 결과를 예측한 것은 아니다. 이는 특정 논문의 실험 결과가 아니다.

언어 지시는 원하는 미래를 지정하지만 관절 명령은 그 미래에 도달하려는 구체적인 행동이다. 이 조건을 구분해야 후보 행동을 비교하는 계획과 폐루프 제어에 예측을 쓸 수 있다. 일반 영상 생성은 그 목적에 맞춰 평가하되 로봇 제어의 근거로 해석할 때는 별도 검증이 필요하다. 근거: 제공 리뷰 §2.1.1–2.1.2, §7.1.
:::

# 작동 메커니즘 | Mechanisms

## 분류 기준

### 예측 표현과 활용 목적은 서로 다른 분류 축이다

| 분류 축 | 비교할 항목 |
| --- | --- |
| 예측 표현 | 잠재 상태·영상·3D·객체·기호 |
| 입력 조건 | 관측 이력·언어·저수준 행동 |
| 정책 연결 | 역동역학·공동 예측·표현 학습 |
| 활용 목적 | 정책 학습·계획·시뮬레이션·평가 |

::: source
Hou et al., 2026, Figure 1·§2–5. arXiv:2605.00080v1.
:::

::: notes
S03 · 75초. 리뷰 §3은 정책과의 결합 구조, §4는 시뮬레이터 활용, §5는 로봇 영상 예측 능력으로 연구를 묶는다. 이를 배타적인 종류로 읽으면 한 모델이 여러 위치에 등장하는 이유를 설명하기 어렵다. 같은 모델이 영상 예측을 하면서 정책 학습과 평가에 모두 쓰일 수 있다.

네 축을 이후 사례에도 적용한다. 구조화된 표현에는 깊이·기하뿐 아니라 객체 관계와 논리적 상태도 포함된다. 잠재 예측과 영상 생성의 원리를 먼저 보고 구조화 방향은 최신 사례에서 다룬다. 근거: 제공 리뷰 Figure 1, §2.1, §3–5.
:::

## 예측 표현

### 잠재 공간 모델은 관측을 압축한 표현에서 미래를 예측한다

- 인코더가 관측을 잠재 표현으로 바꾼다
- 예측기가 미래 표현의 변화를 학습한다
- 예측 표현을 정책 학습이나 계획에 쓴다
- 동역학 모델과 JEPA의 학습 목표는 다르다

![잠재 표현의 예측과 활용](figures/latent-prediction.png "관측 인코딩 → 잠재 예측 → 정책 학습·계획. Dreamer의 동역학 학습과 JEPA의 표현 예측을 구분해 연구자가 제작")

::: source
Hou et al., §3.6; DreamerV3·V-JEPA 2 공식 자료.
:::

::: notes
S04 · 90초. 잠재 표현은 관측을 압축해 예측에 필요한 정보를 담는 공간이다. Dreamer 계열은 경험에서 동역학을 학습하고 상상한 궤적으로 정책을 학습한다. JEPA(Joint-Embedding Predictive Architecture)는 관측의 임베딩을 예측하는 접근이다. 둘을 같은 학습 손실이나 같은 정책 학습 방식으로 설명하지 않는다.

어떤 정보를 남기는지가 중요하다. 시각적 세부를 줄이면 제어에 필요한 정보도 빠질 수 있다. 잠재 공간을 쓴다는 사실만으로 계산 효율과 일반화가 보장되지는 않는다. 근거: 제공 리뷰 §2.1.1, §3.6; https://github.com/danijar/dreamerv3 ; https://github.com/facebookresearch/vjepa2 .
:::

## 예측 표현

### 영상 생성형 모델은 미래를 영상으로 표현한다

- 현재 장면에서 미래 프레임을 생성한다
- 언어·행동 조건으로 생성 방향을 지정한다
- 생성한 미래를 계획·데이터 합성에 활용한다
- 시각적 일관성과 행동 일관성을 함께 검토한다

![조건에 따른 미래 영상](figures/video-prediction.png "현재 관측·언어·행동 조건 → 미래 영상. 모델마다 사용하는 조건이 다름을 표시하고 연구자가 제작")

::: source
Hou et al., 2026, §2.1.2·§5. arXiv:2605.00080v1.
:::

::: notes
S05 · 90초. 생성형 영상 모델은 미래를 사람이 확인할 수 있는 프레임으로 제시한다. 로봇 연구에서는 이를 시각적 계획, 추가 학습 데이터, 행동 조건 시뮬레이션에 활용한다. 확산 기반 접근은 조건을 받아 잡음을 단계적으로 제거한다. 구체적인 구조와 생성 방법은 모델마다 다르다.

영상 모델도 내부에서 압축 잠재 공간을 쓸 수 있다. 여기서 분류하는 기준은 내부 연산 위치보다 최종 예측 대상과 활용이다. 시간적 일관성, 행동 조건, 물리적 타당성, 긴 예측의 안정성을 따로 확인한다. 근거: 제공 리뷰 §2.1.2, §5.2–5.5.
:::

## 제어 연결

### 미래 예측은 역동역학·공동 예측·잠재 학습으로 정책에 연결된다

| 연결 방식 | 행동을 얻는 과정 |
| --- | --- |
| 역동역학 | 현재·목표 미래에서 행동 추론 |
| 공동 예측 | 미래와 행동을 함께 예측 |
| 잠재 학습 | 예측 표현을 정책 학습에 활용 |

![예측에서 정책으로 이어지는 경로](figures/policy-coupling.png "역동역학·미래와 행동의 공동 예측·예측 표현을 이용한 정책 학습을 별도 경로로 표현. 리뷰 §3을 근거로 연구자가 제작")

::: source
Hou et al., 2026, §3.2–3.6·Table 1.
:::

::: notes
S06 · 75초. 역동역학은 상태 변화를 만드는 행동을 추론한다. 미래를 먼저 생성하고 현재와 그 미래 사이의 행동을 얻는 경로가 여기에 해당한다. 공동 예측은 행동과 미래를 하나의 생성 과정에서 연결한다. 잠재 학습은 예측 표현이 정책 학습이나 계획을 돕는 경로다.

이 표는 이해를 위한 묶음이다. 단일 백본, 전문가 혼합, 통합 VLA(Vision-Language-Action) 등 리뷰의 세부 구조는 경로를 구현하는 방법이며 하나의 범주에만 속하지 않을 수 있다. 공동 학습했다고 배포 때마다 미래 영상을 끝까지 생성하는 것도 아니다. 근거: 제공 리뷰 §3.2–3.6, Table 1.
:::

## 제어 연결

### 학습된 시뮬레이터는 정책 학습·계획·평가에 쓰인다

- 정책 학습: 가상 경험에서 행동을 개선한다
- 계획: 후보 행동의 예측 결과를 비교한다
- 평가: 예측 환경에서 정책을 시험한다
- 실환경과의 차이가 세 활용 모두에 영향을 준다

::: source
Hou et al., 2026, §4.1–4.2. arXiv:2605.00080v1.
:::

::: notes
S07 · 60초. 학습된 시뮬레이터는 데이터에서 얻은 환경 모델이다. 규칙이나 물리 엔진으로 만든 시뮬레이터와 학습 방식이 다르다. 정책 학습은 경험을 늘리는 용도, 계획은 지금의 후보 행동을 고르는 용도, 평가는 정책의 성능을 추정하는 용도다.

예측 오류는 각 용도에서 다른 문제를 만든다. 정책은 모델 오류를 이용하는 행동을 학습할 수 있고 계획은 잘못된 후보를 고를 수 있으며 평가는 실제 정책 순위를 틀리게 추정할 수 있다. 활용 목적에 맞는 신뢰성 검증이 필요하다. 근거: 제공 리뷰 §4.1–4.2.
:::

# 대표 모델 비교 | Representative Models

## DreamerV3

### DreamerV3는 상상한 궤적으로 행동 정책을 학습한다

- 실제 경험에서 월드 모델을 학습한다
- 잠재 공간에서 미래 궤적을 상상한다
- 상상한 궤적으로 actor-critic을 학습한다
- 정책 학습과 온라인 행동 탐색을 구분한다

![Dreamer의 상상 기반 정책 학습](figures/dreamer-loop.png "실제 경험 → 월드 모델 → 상상 궤적 → actor-critic 학습. 저자 공식 자료를 근거로 연구자가 제작")

::: source
Hafner et al., DreamerV3. danijar.com/dreamerv3.
:::

::: notes
S08 · 90초. 실제 환경 경험으로 월드 모델을 학습하고 그 안에서 만든 궤적으로 actor와 critic을 개선한다. 배우는 정책과 경험을 예측하는 모델의 역할을 구분한다. 상상한 궤적을 학습에 쓴다는 설명을 매 행동 시점마다 후보를 온라인 탐색한다는 뜻으로 바꾸지 않는다.

게임이나 제어 과제의 결과를 로봇 접촉 과제 성능으로 일반화하지 않는다. 출처: Hafner et al., Mastering Diverse Control Tasks through World Models, Nature, 2025; https://danijar.com/dreamerv3/ ; https://github.com/danijar/dreamerv3 .
:::

## V-JEPA 2

### V-JEPA 2-AC는 행동 조건을 더한 잠재 예측을 계획에 활용한다

- V-JEPA 2는 영상에서 표현 예측을 학습한다
- 2-AC는 로봇 데이터로 행동 조건을 추가한다
- 미래 잠재 표현을 행동 계획에 활용한다
- 영상 이해 성능과 제어 성능을 구분한다

![표현 학습에서 행동 조건 계획으로](figures/vjepa-planning.png "영상 기반 표현 학습 → 로봇 데이터의 행동 조건 후학습 → 잠재 예측으로 계획. V-JEPA 2와 2-AC를 구분해 연구자가 제작")

::: source
Assran et al., V-JEPA 2, 2025. arXiv:2506.09985.
:::

::: notes
S09 · 90초. 기본 V-JEPA 2와 행동 조건을 추가한 V-JEPA 2-AC를 구분한다. 영상에서 얻은 표현을 곧바로 로봇 제어의 결과로 해석하지 않고 로봇 상호작용 데이터로 어떤 연결을 추가하는지 본다. 2-AC는 잠재 공간의 미래 예측을 로봇 계획에 쓰는 사례다.

# 한계와 평가 | Limitations and Evaluation

## 배포 한계

### 행동 조건이 약하면 그럴듯한 예측도 제어에서 어긋날 수 있다

- 이력·목표만으로 그럴듯한 미래를 만들 수 있다
- 행동을 바꿨을 때 예측 변화가 맞는지 확인한다
- 의도에 맞는 미래와 행동의 실제 결과를 구분한다
- 미래 상태를 입력하는 정보 누설을 점검한다

::: source
Hou et al., §8.1; Kim et al., arXiv:2607.22535.
:::

::: notes
S16 · 65초. 목표나 과거 이력만으로 성공 장면을 잘 생성할 수 있다. 후보 행동을 비교하려면 행동을 바꿨을 때 어떤 결과가 달라지는지 예측해야 한다. 조건에 행동 벡터를 넣었다는 사실만으로 이 관계를 충분히 학습했다고 결론 내릴 수 없다.

같은 시작 상태에 다른 행동을 입력하는 비교로 확인할 수 있으며 실제 검증에서는 환경 조건을 통제해야 한다. 실행 이후에만 알 수 있는 신호를 입력하는지도 점검한다. 근거: 제공 리뷰 §8.1 Causal Conditioning Gaps; https://arxiv.org/abs/2607.22535 의 정보 누설 설명.
:::

## 배포 한계

### 오차 누적·물성 관측·계산 지연은 실제 배포를 제한한다

- 긴 예측에서 오차가 누적된다
- 영상만으로 마찰·강성·접촉을 알기 어렵다
- 새로운 물체·환경에서 일반화를 확인해야 한다
- 예측 지연이 제어 주기를 제한한다

::: source
Hou et al., 2026, §7.2·§8.2–8.5.
:::

::: notes
S17 · 65초. 세부 장면을 잘 생성해도 긴 시간 동안 상태가 계속 정확하다는 보장은 없다. 가림이나 접촉 변화로 오차가 생기면 이후 예측으로 이어질 수 있다. 영상에 잘 드러나지 않는 마찰·강성 같은 물성은 별도 관측과 데이터가 중요하다.

리뷰는 촉각·힘 정보, 구조화된 표현, 고전 제어와의 결합, 계산 효율을 연구 방향으로 다룬다. 각각 추가 비용과 문제가 있어 완성된 해법으로 소개하지 않는다. 분포 밖 일반화와 실제 제어 주기에 맞는 추론 지연을 확인한다. 근거: 제공 리뷰 §7.2, §8.2–8.5.
:::

## 평가

### 영상 품질과 폐루프 제어 성능은 따로 검증해야 한다

| 평가 목적 | 확인할 내용 |
| --- | --- |
| 영상 예측 | 시각적·시간적 일관성 |
| 행동 예측 | 행동 민감도·물리적 타당성 |
| 폐루프 제어 | 실제 관측 갱신·과제 성공 |
| 정책 평가 | 예측 순위와 실제 순위의 일치 |

::: source
Hou et al., 2026, §7.1·§7.3·§8.6.
:::

::: notes
S18 · 80초. 개방 루프 평가는 정해진 입력에서 예측을 만든 뒤 실제 데이터와 비교한다. 폐루프 평가는 선택한 행동을 실행하고 새 관측을 받아 다음 행동을 정하는 반복을 포함한다. 영상 품질이 높아도 이 반복에서 좋은 의사결정을 한다는 증거는 따로 필요하다.

월드 모델에서 좋다고 판단한 정책이 실제 환경에서도 좋은지 확인해야 한다. 리뷰는 과제 성공, 정책 순위 신뢰성, 실행 가능성 등 기능 중심 평가를 강조한다. 데이터·환경·행동 공간·평가 절차가 같은지 확인한 뒤 결과를 비교한다. 근거: 제공 리뷰 §7.1, §7.3, §8.6.
:::

## 정리

### 표현 방식과 제어 연결에 따라 월드 모델의 쓸모와 한계가 달라진다

- 종류: 예측 표현과 활용 목적을 나눠 본다
- 메커니즘: 미래 예측에서 행동까지의 경로를 본다
- 동향: 통합·구조화·제어 연결을 비교한다
- 한계: 행동 일관성과 실제 제어 효용을 검증한다

S20 · 30초. 월드 모델은 미래를 예측해 행동을 돕지만 무엇을 표현하고 어떻게 제어와 연결하는지에 따라 쓸모와 한계가 달라진다. 통합과 구조화는 사례를 묶은 관점이며 연구 전체를 전수 조사한 결론은 아니다.
