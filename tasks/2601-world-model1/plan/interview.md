# 발표 인터뷰

## 확인한 사용자 요구

- 기준 논문: 사용자가 지정한 `World Model for Robot Learning: A Comprehensive.pdf`.
- 청중: 로보틱스 연구실. 딥러닝·강화학습 기초는 알고 월드 모델은 처음이다.
- 시간과 목표: 30분, 최신 연구 비교와 한계까지 상세히 다룬다.
- 범위: 발표일 기준 공개 연구를 대상으로 영상·게임·로봇을 폭넓게 비교한다.
- 필수 내용: 종류, 작동 메커니즘, 최신 트렌드, 한계.
- 추가 후보: 사용자 요청에 따라 NVIDIA Cosmos를 포함한다.

## 자료에서 확인한 사실

제공 PDF는 Hou et al.의 **World Model for Robot Learning: A Comprehensive Survey**다. 표지에 `arXiv:2605.00080v1`, `30 Apr 2026`이 적혀 있으며 43쪽이다. 루트의 제공 파일을 보존하고 동일한 사본을 `sources/`에 두어 승인 입력 해시에 포함했다.

논문은 로봇 중심의 기능적 정의를 사용한다. §2.1에서는 현재 상태/관측과 행동 또는 고수준 지시를 조건으로 미래를 예측하고, 이 예측이 체화된 의사결정에 어떻게 쓰이는지를 강조한다. 시각적으로 그럴듯한 미래 영상만으로 제어에 유용한 월드 모델임을 입증할 수는 없다.

Figure 1(2쪽)과 본문은 서로 다른 분류 축을 사용한다.

- §3: 정책과 월드 모델의 결합 구조. 역동역학, 단일 백본, 전문가 혼합, 통합 VLA, 잠재 공간 예측 등을 다룬다.
- §4: 학습된 시뮬레이터의 활용. 강화학습과 정책 평가를 다룬다.
- §5: 로봇 영상 예측 능력. 상상 기반 활용, 행동 제어 가능성, 구조 정보, 기반 모델을 다룬다.
- §6: 내비게이션과 자율주행으로 연결한다.
- §7: 데이터와 평가를 다룬다. 영상 품질, 제어 효용, 정책 평가를 함께 검토해야 한다.
- §8: 인과적 조건화, 효율, 다중 감각, 고전 제어·기호 구조와의 결합, 평가 기준의 한계를 다룬다.

이 분류들은 배타적인 모델 종류가 아니다. 한 모델이 여러 축에 동시에 속할 수 있으므로 발표용 분류도 표현 방식과 활용 방식을 분리한다.

## 에이전트의 기획 제안

월드 모델의 기본 예측 문제를 먼저 설명하고, **무엇을 예측하는가 → 행동과 어떻게 연결되는가 → 어디에 쓰는가 → 어떤 조건에서 실패하는가**의 순서로 이해를 돕는다. 이는 아직 선택·승인된 스토리라인이 아니며, Stage 2에서 후보 2~3개를 비교한다.

대표 메커니즘은 잠재 동역학, 생성형 영상 예측, 구조화된 3D/객체 표현 등을 비교할 수 있다. 정책 결합에서는 미래에서 행동을 추론하는 방식, 미래와 행동을 함께 예측하는 방식, 잠재 예측을 정책 학습에 쓰는 방식을 구분한다. 세부 사례와 설명 깊이는 원문 확인 후 정한다.

영상은 미래 생성, 게임은 상호작용 가능한 환경, 로봇은 물리적 행동과 제어 연결이라는 비교 관점으로 접근한다. 이 구분은 발표를 위한 관점이며 각 연구의 가능성을 제한하는 정의로 쓰지 않는다.

## 최신 자료의 범위와 확인 수준

검색일은 **2026-10-11**, 기존 표지의 발표일은 **2026-10-12**다. 아직 공개되지 않은 연구를 포함하지 않는다. ‘가장 최신’은 확인한 공개 자료 안에서의 최신 사례를 뜻하며 완전한 전수 조사를 뜻하지 않는다.

2026-07-24의 Robot-Factored World Models와 2026-10-06의 DepthWorld는 arXiv 원문 페이지의 제출일과 초록을 확인했다. 각각 로봇별 행동 실현/렌더링 분리와 3D 기하 예측을 보완 후보로 기록한다. 상세 실험 결과는 아직 검토하지 않았으므로 성능 우위를 주장하지 않는다. Genie 3는 공식 소개를 확인한 게임형 환경 비교 후보이며 최신 로봇 제어 성능의 근거로 사용하지 않는다.

NVIDIA Cosmos를 사용자 요청으로 후보군에 추가했다. 2026-10-11에 NVIDIA 공식 모델군 안내와 Cosmos 3 연구 페이지를 확인했다. Cosmos는 모델군과 도구를 포함하므로 하나의 단일 모델로 취급하지 않는다. Predict·Transfer·Reason의 역할 구분, Cosmos Policy의 로봇 제어·계획 연결, Cosmos 3의 다중 모달 통합을 비교 후보로 둔다. 버전별 구조·공개 시점·실험 조건은 상세 검토 후 최종 사례를 선정하며 공식 소개만으로 물리적 신뢰성이나 성능 우위를 단정하지 않는다.

## 성공·실패 기준과 피할 오해

좋은 발표는 청중이 새로운 모델을 보았을 때 입력 조건, 예측 표현, 행동 선택 과정, 검증 방법을 스스로 물을 수 있게 한다. 모델 이름의 열거에 그치거나 영상 데모를 물리적 이해의 증거로 단정하면 목적을 달성하지 못한다.

- 리뷰 전체가 영상·게임의 모든 월드 모델을 포괄한다고 해석하지 않는다.
- 언어 조건과 저수준 행동 조건의 차이를 지우지 않는다.
- 잠재 예측 모델이 모두 미래 영상을 생성한다고 설명하지 않는다.
- 모델이 예측하는 과정과 정책이 행동을 선택하는 과정을 구분한다.
- 개방 루프 영상 평가와 폐루프 제어 평가를 구분한다.
- 긴 시계열의 오차 누적, 접촉/마찰 등 관측하기 어려운 물성, 분포 밖 일반화, 계산 지연, 평가 신뢰성의 한계를 검토한다.
- 서로 다른 데이터·벤치마크·실험 조건의 성공률로 모델의 보편적 우열을 정하지 않는다.
