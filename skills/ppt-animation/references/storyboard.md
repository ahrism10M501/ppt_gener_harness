# 애니메이션 storyboard

제작 전 점검표다. 필요한 항목만 채운다. 장면이 여러 개면 `plan/animation.md`에 두고 슬라이드 노트와 연결한다.

```yaml
slide_id: S03
audience: 청중이 이미 아는 용어와 아직 모르는 개념
claim: 이 장면을 보고 이해해야 할 문장 하나
motion_reason: 연속 변화가 필요한 이유와 정적 대안
evidence: sources/ 경로, Truth Model 항목, 또는 합성 교육 예제임을 명시
misconception: 관객이 혼동할 수 있는 전제나 해석
visual_mapping: 기호·색·선·위치가 각각 뜻하는 것
equations: 화면 요소와 계산식의 대응 및 가정
beats:
  - state: 처음 관찰할 상태
    change: 변하는 요소와 고정되는 요소
    explanation: 발표자가 말할 설명
    hold: 읽고 생각할 시간을 둘 지점
poster: 정지해도 claim을 이해할 수 있는 상태
playback: 단발/반복과 끝 상태·재시작 구분
```

## 장면 구성

- 한 장면에 주장 하나를 둔다. 기호를 도입하고, 상태를 보여 주고, 변화와 결과 순으로 설명한다.
- 수식의 변수와 실제로 움직이는 점·선·축을 대응시킨다. 관객이 모르는 기호를 동시에 여러 개 추가하지 않는다.
- 속도는 읽을 시간에 맞춘다. 수치·기호가 바뀌는 순간과 결과를 확인하는 순간에 멈춤을 둔다. 비교 장면 사이에는 축 범위를 고정한다.
- 재생 시간은 물리 시간·학습 속도와 다를 수 있다. 실제 시간이 중요하면 화면에 시간·반복 번호와 재생 배율을 표시한다.
- 짧은 장면은 8~20초, 12~24fps로 시작해 가독성과 파일 크기를 보고 조정한다.
- 반복 재생 시 끝에서 처음으로 돌아가는 순간이 역방향 과정으로 보이지 않게 정지·구분 표시를 넣거나 단발 재생한다.

## 계산 기록

반복 최적화라면 목적함수·미분·갱신식·초기값·학습률·정지 조건을 기록하고 표시되는 숫자와 검산한다. 목적함수·모델·데이터·학습 규칙을 구분하고, 교육용 결과를 실험 성능이나 일반적 보장으로 표현하지 않는다.

## PPTX 확인

PPTX ZIP의 GIF 미디어가 원본과 같은지, 정적 렌더가 대표 PNG를 썼는지 확인한다. PPTX에 GIF가 보존된 것과 실제 PowerPoint 재생은 별개의 검증이다.
