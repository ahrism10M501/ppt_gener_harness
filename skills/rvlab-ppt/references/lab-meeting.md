# 랩미팅용 RVLAB 발표 가이드

`templates/examples/`의 실제 연구실 발표 네 편(3DGS 기술 리뷰·구현, GS-ICP SLAM과 CaRtGS 논문 리뷰, CNN 스터디, 학습 루프 스터디·실험)에서 확인한 구성과 반복되는 문제를 정리했다. 양식 규칙은 저장소 루트의 `DESIGN.md`가 우선한다.

## 발표 유형별 뼈대

목차는 섹션(`#`)이 Chapter가 되고 토픽(`##`)이 그 아래 항목이 된다. 시간은 슬라이드당 약 1분으로 잡고 청중과 목적에 맞춰 줄인다.

| 유형 | 섹션 순서 | 마지막에 둘 것 |
| --- | --- | --- |
| 진행 보고 | 지난 미팅 피드백·이번 목표 → 한 일과 설정 → 결과(비교 기준·조건) → 문제와 원인 가설 → 다음 계획 | 교수님·동료에게 받고 싶은 판단이나 질문 |
| 논문 리뷰 | 문제와 동기 → 핵심 아이디어 → 방법 구성요소 → 실험 설정·결과 → 한계와 우리 연구와의 연결 | 우리 실험에 적용할 점과 열린 질문 |
| 스터디·튜토리얼 | 왜 필요한가 → 개념·원리 → 핵심 코드와 실행 결과 → 정리 | 다음 스터디 범위. 긴 코드·추가 예제는 `# Appendix` |

여러 논문이나 기법을 다루면 각각을 섹션으로 두고 같은 토픽 이름으로 여러 장을 이어 쓴다(예: `GS-ICP SLAM` 5장, `CaRtGS` 4장). 이전 발표를 이어 가는 스터디는 첫 섹션에 지난 내용 요약을 한 장 둔다.

## 좋은 슬라이드의 조건

- 상단 바는 토픽 이름, `###`는 청중이 기억할 결론이다. 결론 없이 “ICP란?”처럼 질문만 두지 않는다. 질문형이면 본문 첫 줄에서 바로 답한다.
- 문단 대신 근거 2~4개를 불릿으로 쓴다. 예제의 14~17pt 긴 문단 슬라이드는 랩미팅에서 읽히지 않는다. 설명은 `::: notes`로 옮긴다.
- 결과 슬라이드에는 비교 기준·조건·표본 수·단위를 함께 적는다. 학습 loss와 실제 평가 성공률을 섞지 않는다.
- 논문 그림·표에는 `::: source`로 저자·연도·링크를 단다. 전체 서지는 노트에 둔다.
- 코드는 핵심 15줄 이내로 자르고, 실행 결과(그래프·출력)를 옆이나 다음 장에 붙인다. 코드 스크린샷 대신 코드 블록을 쓴다.
- 빈 슬라이드, 목차와 다른 상단 바 이름, 두 줄로 넘치는 상단 바(예: `Where is Skip-Connection Now`)를 만들지 않는다.

## 그림 제안

그림은 연구자가 만든다. 에이전트는 슬라이드마다 필요한 그림을 제안하고 자리를 잡는다. 사용자가 명시적으로 요청한 경우에만 자료로 그래프를 그린다.

1. 기획 단계에서 `plan/outline.md`의 `figure`에 제안을 적는다: 무엇을 보여 줄지, 축·비교 대상·단위, 만들 수 있는 자료(`sources/…`), 없으면 무엇이 더 필요한지.
2. `slides.md`에 `![짧은 캡션](figures/이름.png "요청 내용")`으로 자리를 잡는다. 파일 이름은 내용을 드러내는 영문 소문자·하이픈으로 정한다.
3. `uv run rvppt lint`의 `missing_figures` 목록을 연구자에게 전달한다. 빌드는 해당 자리에 점선 요청 상자를 그린다.
4. 연구자가 넣은 초안 PPT의 그림을 재사용할 수 있으면 `figures/draft/`로 꺼낸 파일을 제안한다.

좋은 제안은 그림 하나가 핵심 문장 하나를 증명하도록 한다. 예: “제안 방법이 BC보다 성공률이 높다” → `x: 조건(BC·ACT·제안), y: 성공률(%), 막대 위에 시행 수, sources/eval.csv`. 논문 그림을 쓰려면 원 논문의 그림 번호와 출처를 함께 제안한다.

## 빌드 후 확인

`.build/output/contact-sheet.png`와 각 `slide-NN.png`를 직접 보고 다음을 확인한다.

- 표지의 발표일시·제목·부제·발표자·소속이 맞다.
- 목차의 Chapter와 섹션 슬라이드, 항목과 상단 바 이름이 일치한다.
- 상단 바가 한 줄이고 파란 선이 제목 오른쪽에서 시작한다.
- 각 슬라이드가 핵심 문장 하나를 그림·표·불릿으로 뒷받침한다.
- 요청 상자로 남은 그림과 출처 없는 인용이 무엇인지 보고한다.
